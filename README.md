# FamilyHub — путь изучения React

Учебный проект, в котором знания React сразу превращаются в полезное семейное приложение.

![Дорожная карта FamilyHub](assets/familyhub-react-roadmap-poster.png)

## Как пользоваться

1. Открой [ROADMAP.md](ROADMAP.md) и проходи этапы по порядку.
2. Отмечай выполненные пункты в [CHECKLIST.md](CHECKLIST.md).
3. Открой [MINDMAP.md](MINDMAP.md) в [Markmap](https://markmap.js.org/repl), чтобы смотреть и редактировать карту.

## Что получится

FamilyHub — адаптивное приложение для семьи с модулями воды, настроения, покупок, задач, меню, ухода за растениями, дыхания, календаря и настроек.

Каждый этап заканчивается небольшой работающей частью приложения. Так портфолио растёт одновременно со знаниями.
